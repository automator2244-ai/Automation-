# EZ.Path.AI · חתימה דיגיטלית על הצעות מחיר

אפליקציה שמאפשרת ללקוחות לחתום דיגיטלית על הצעות מחיר דרך קישור בוואטסאפ.

**איך זה עובד:** מעלים הצעת מחיר (PDF/תמונה מקאנבה) → ממקמים שדה חתימה → שולחים קישור.
הלקוח פותח, מזין מייל, צופה, חותם (ציור באצבע או הקלדת שם), ומאשר. אז נשלח מייל
אליך תמיד (עם ה-PDF החתום), ועותק ללקוח אם ביקש.

- **חינם לחלוטין** — Cloudflare (Pages/Functions/D1/R2) + Resend, בשכבות החינם.
- **לא נרדם** — זמין מיד גם אחרי שבועות בלי שימוש.
- **מאובטח** — קישורים אקראיים, נעילה אחרי חתימה, ראיות (מייל/שעה/IP), אזור ניהול מאחורי Cloudflare Access.

## הקמה ופריסה
ראה **[SETUP.md](./SETUP.md)** — מדריך שלב-אחר-שלב מלא (Cloudflare, DNS, Resend, Access).

## הרצה מקומית
```bash
npm install
npm run db:init:local
npm run build
npm run preview   # http://localhost:8788
```
